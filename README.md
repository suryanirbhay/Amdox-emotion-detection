# Amdox Emotion Intelligence

Amdox is a Streamlit app for emotion analysis and employee wellness tracking.

## Features

- Text-based emotion prediction
- Facial emotion detection via image upload or webcam
- Stress scoring and task recommendations
- HR analytics dashboard with charts and employee risk review

## Run locally

```bash
python -m pip install -r requirements.txt
streamlit run app.py
```

## Notes
